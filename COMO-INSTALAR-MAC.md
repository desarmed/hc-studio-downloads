# Instalar o HC Studio no Mac

Baixe o arquivo **HC Studio_0.3.4_aarch64.dmg** pelo link que recebeu.

1. Abra o arquivo baixado.
2. Arraste **HC Studio** para a pasta **Applications** que aparece na janela.
3. Abra **HC Studio** em Applications.

## Primeiro uso

Como esta versão não usa uma assinatura da Apple, o macOS pode bloquear a primeira abertura.
Se isso acontecer, vá em **Ajustes do Sistema > Privacidade e Segurança**, clique em
**Abrir Mesmo Assim** para o HC Studio e confirme em **Abrir**.

Isso é necessário somente uma vez. Depois, abra o HC Studio normalmente em Applications.

Não é preciso usar Terminal, clicar com o botão direito, nem ter conta no GitHub.
